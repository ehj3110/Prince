## 🚨 Troubleshooting

### Import Errors
**Problem**: "ModuleNotFoundError"
**Solution**: Make sure you're in the correct directory
```powershell
cd "C:\Users\ehunt\OneDrive\Documents\Prince\Prince_Segmented_20250926\post-processing"
```

### Git Conflicts
**Problem**: "Your branch has diverged"
**Solution**: 
```powershell
git fetch origin
git status
# If you want to keep your changes:
git pull --rebase origin main
# Or, if you want to discard local changes:
git reset --hard origin/main
```

### Missing Data
**Problem**: "MASTER CSV not found"
**Solution**: Run batch processing first
```powershell
python batch_process_steppedcone_generalized.py --folder V3
```
